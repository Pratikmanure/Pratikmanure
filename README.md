## Featured Projects

### FraudStream Command Center
A portfolio project that simulates a real-time fraud detection workflow using **Python, SQLite, SQL window functions, and Streamlit**. It generates synthetic credit card transactions, flags suspicious patterns like velocity spikes and impossible travel, and visualizes alerts through a live dashboard.

**Highlights:**
- Real-time style transaction simulation with micro-batches
- SQL-based anomaly detection using window functions
- Explainable fraud scoring and categorization
- Streamlit dashboard for alert monitoring and hotspot analysis

Repo: [FraudStream Command Center](https://github.com/Pratikmanure/fraud_pipeline)

### QuantView Terminal
A market analytics and strategy analysis dashboard built with **Streamlit, Pandas, CCXT, SQLite, and technical indicators**. It supports portfolio analysis, strategy comparison, replay workflows, and optimization for trading experiments.

**Highlights:**
- Interactive market dashboard with multiple asset views
- EMA-based strategy testing and optimization
- Portfolio mode and strategy comparison workflows

Repo: [QuantView Terminal](https://github.com/Pratikmanure/staging_quantview)
